# CMPUT 403: Algorithmics in Competitive Programming

## What It Covers

Weekly problem sets (usually 3-4 problems, each open for two weeks) on a Kattis judge, all or nothing per problem: you get full marks only if your solution passes every hidden test case. Topics run a week at a time: dynamic programming, graph algorithms, geometry, string algorithms, combinatorics, data structures, network flow, bipartite matching, and number theory. Lecture code is in C++; you can submit in any language Open Kattis supports, though Python and Java can be too slow on tight problems. 403 shares lectures with [CMPUT 303](cmput-303.md) but adds harder problems, advanced topics like max flow and FFT, and an extra project. In Friggstad's offerings there's no traditional midterm or final. ([instructor's 303/403 info page](https://friggstad.github.io/cmput403_info.html))

## What Students Say

> Imported from the original course reviews page, which mixed student contributions with summarized Reddit discussion. Tips aren't term-stamped yet; if you've taken this course recently, [add your experience](https://github.com/uofa-cs/uofa-cs-wiki/issues/new?template=course-review.yml).

Reddit reviews are consistently positive, and students often call it the best interview prep at UofA. The format is uncomfortable at first and then deeply satisfying for students who stick with it.

**Instructor notes:**
- **Zachary Friggstad:** active on Discord and generous with partial solutions that get the right idea. Students rave about his offering.

**Student tips:**
- Pick between 303 and 403 honestly: the instructor recommends 403 only if you already have a competitive programming background, and 303 otherwise. The extra hard problem each week takes much more time than it looks.
- Do problems on Kattis regularly throughout the semester; don't try to cram.
- With no final exam, the workload is steady across the term rather than piling up during finals.
