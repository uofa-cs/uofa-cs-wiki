# CMPUT 267: Machine Learning I

## What Students Say

> Imported from the original course reviews page, which mixed student contributions with summarized Reddit discussion. Tips aren't term-stamped yet; if you've taken this course recently, [add your experience](https://github.com/uofa-cs/uofa-cs-wiki/issues/new?template=course-review.yml).

Statistics-heavy intro to ML: linear algebra, probability, gradient descent, regression, classification. This is not a "here's how to use scikit-learn" course. It's mathematical foundations. Coding is in Python on Google Colab (per the [Fall 2025 course site](https://vladtkachuk4.github.io/machinelearning1/), which had 8 assignments with at least 3 involving code, plus two midterms and a final).

One student summarized it well: "It's basically applied stats. That's what a lot of ML is." Another: "My roommate took 267 and it was TOUGH."

**Student tips:**
- Strong stats and linear algebra background (MATH 125, STAT 151/252) helps a lot.
- Don't take this with 379 or other heavy courses. One student who took 379, 401, and 267 in the same semester was specifically advised to drop 267.
- 267 is one of the ways into [365](cmput-365.md) (Introduction to Reinforcement Learning), which requires one of 267, 466, or STAT 265.
