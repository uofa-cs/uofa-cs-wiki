# CMPUT 272: Formal Systems and Logic in Computing Science

## What Students Say

> Imported from the original course reviews page, which mixed student contributions with summarized Reddit discussion. Tips aren't term-stamped yet; if you've taken this course recently, [add your experience](https://github.com/uofa-cs/uofa-cs-wiki/issues/new?template=course-review.yml).

Propositional logic, predicate logic, proofs, set theory. Dry but necessary. Many students find it tedious; the students who actually absorb the proof-writing skills are better prepared for theory courses.

**Student tips:**
- Do all the practice problems. The exam questions mirror practice closely.
- 272 is a prerequisite for [204](cmput-204.md), [291](cmput-291.md), [331](cmput-331.md), [366](cmput-366.md), and [416](cmput-416.md), and a corequisite of [267](cmput-267.md), so take it early. The proof skills carry straight into algorithms.
