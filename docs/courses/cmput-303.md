# CMPUT 303: Algorithmics in Practice

## What It Covers

303 shares lectures with [CMPUT 403](cmput-403.md) and was created as the more accessible version for students without a programming contest background. Each week covers one topic (dynamic programming, graph algorithms, and so on), and you solve weekly problem sets of 3-4 problems on a Kattis judge: a problem only counts if it passes every hidden test case. Lecture code is in C++, but you can submit in any language Open Kattis supports (Python is often too slow for the tighter problems). In Zachary Friggstad's offerings, your grade comes from the weekly sets plus an open pool of contest-style problems; there's no project. ([instructor's 303/403 info page](https://friggstad.github.io/cmput403_info.html))
