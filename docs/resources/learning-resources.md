# Learning Resources

Resources organized by the course they help with, then a short list for beyond the degree. Where a course actually uses a resource, we say so and link the source; everything else is a companion we recommend. For what each course covers, see the [Curriculum Map](../skills/curriculum-map.md).

---

## By Course

| Course | Resource | Why |
|---|---|---|
| 174 / 175 | [The Python Tutorial](https://docs.python.org/3/tutorial/) | The official one; better than most paid courses for filling gaps |
| 201 | K. N. King, [*C Programming: A Modern Approach*](http://knking.com/books/c2/), 2nd ed. | The required text in Fall 2025 ([course site](https://webdocs.cs.ualberta.ca/~ghlin/cmput201.php)) |
| 204 / 304 | *Introduction to Algorithms* (CLRS), plus [MIT 6.006](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/) | CLRS is the standard reference (201's Fall 2025 site recommends it too); 6.006 has free lectures if a topic doesn't click |
| 229 | The course's [public RISC-V labs](https://cmput229.github.io/229-labs-RISCV/) and the [RARS simulator](https://github.com/TheThirdOne/rars) | Install RARS early and work through Lab 1 before it's due |
| 267 / 466 / 467 | [Machine learning notes](https://marthawhite.github.io/mlbasics/notes.pdf) from 267 | The textbook for 267 in Winter 2023 ([course site](https://marthawhite.github.io/mlbasics/)); the clearest bridge into 466/467 |
| 466 / 467 | Bishop, [*Pattern Recognition and Machine Learning*](https://www.microsoft.com/en-us/research/wp-content/uploads/2006/01/Bishop-Pattern-Recognition-and-Machine-Learning-2006.pdf) (free PDF); [*Dive into Deep Learning*](https://d2l.ai) | Bishop for the theory; D2L for neural nets with runnable code |
| 303 / 403 | [Open Kattis](https://open.kattis.com), [*Competitive Programming 4*](https://cpbook.net/details?cp=4), [CSES Handbook](https://cses.fi/book/index.php) | The course is graded on a UofA Kattis site, and the instructor suggests CP4 ([info page](https://friggstad.github.io/cmput403_info.html)); the CSES handbook is a free alternative |
| 313 | Kurose and Ross, *Computer Networking: A Top-Down Approach*; [authors' site](https://gaia.cs.umass.edu/kurose_ross/) | The standard networking text; the authors post free lecture videos and interactive problems |
| 325 | [Learn Prolog Now!](https://lpn.swi-prolog.org/) | Free, interactive, and runs Prolog in the browser |
| 365 / 366 | Sutton and Barto, [*Reinforcement Learning: An Introduction*](http://incompleteideas.net/book/RLbook2020.pdf) (free PDF); UofA's [RL specialization on Coursera](https://www.coursera.org/specializations/reinforcement-learning) | Sutton is UofA faculty and shared the [2024 Turing Award](https://awards.acm.org/xpages/turing/index) with Barto for this work; 365 uses the UofA RL MOOC ([catalogue](https://apps.ualberta.ca/catalogue/course/cmput/365)) |
| 379 | [*Operating Systems: Three Easy Pieces*](https://pages.cs.wisc.edu/~remzi/OSTEP/) (free) | Short chapters that line up well with processes, concurrency, and file systems |
| 404 | [MDN Learn web development](https://developer.mozilla.org/en-US/docs/Learn_web_development) | 404 expects you to write plain HTML/CSS/JS ([project spec](https://uofa-cmput404.github.io/general/project.html)); MDN is the reference |
| 415 | [*Crafting Interpreters*](https://craftinginterpreters.com) (free); [MLIR Toy tutorial](https://mlir.llvm.org/docs/Tutorials/Toy/) | Crafting Interpreters for the big picture; the Toy tutorial for the MLIR you'll use ([course templates](https://github.com/cmput415)) |

## Beyond the Degree

- **Gaps in the curriculum** (system design, frontend, containers, CI, production): one resource per gap on the [Curriculum Map](../skills/curriculum-map.md#filling-the-gaps).
- **Tools:** [The Missing Semester](https://missing.csail.mit.edu) for the shell, Git, and debugging.
- **A self-study map:** [Teach Yourself Computer Science](https://teachyourselfcs.com) if you want to see what a full CS curriculum looks like outside UofA.
- **Practice:** [Advent of Code](https://adventofcode.com) every December, good for picking up a new language.
